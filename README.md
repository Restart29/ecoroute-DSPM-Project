# 🌱 EcoRoute AI | Scope 3 Freight Decarbonization Platform

**EcoRoute AI** is an enterprise-grade machine learning application designed to optimize supply chain logistics, reduce Scope 3 upstream transport emissions, and ensure compliance with ISO 14083 and GLEC accounting standards.

Developed as a capstone project, this platform ingests the Brazilian E-Commerce Public Dataset (Olist) to simulate real-world multimodal freight arbitrage, pitting XGBoost and Deep Neural Networks against each other to deliver verifiable carbon transparency.

## 🚀 Key Features

- **Multi-Modal Carbon Inference:** Predicts baseline diesel road emissions and simulates the exact CO2e and line-haul cost reductions of shifting freight to Intermodal Rail or Coastal Cabotage (Sea).

- **ISO 14083 / GLEC v3.0 Compliance:** Calculates emissions using verified Tier-3 default activity methods ($0.102\text{ kg CO}_2\text{e} / \text{tonne-km}$ for road).

- **Spatial Network Optimization (K-Means):** Unsupervised clustering of historical customer coordinates to identify the 5 optimal regional consolidation hubs, reducing average transit distances by \~28%.

- **Dual-Model Benchmarking:** Compares Gradient Boosted Trees (XGBoost) against a Deep Multi-Layer Perceptron (Neural Network) using 5-Fold Cross-Validation.

- **Executive Explainability (SHAP):** Transparent feature attribution via SHAP TreeExplainer to prove regulatory compliance for ESG auditors.

- **Interactive Cockpit (Streamlit):** A 5-tab executive UI featuring Plotly geospatial maps, real-time modal trade-off simulators, and an automated Scope 3 Audit Memo generator.

## ⚙️ Installation & Usage

**1. Clone the repository and set up your environment:**

```
git clone https://github.com/your-username/ecoroute-ai.git
cd ecoroute-ai
pip install -r requirements.txt


```

**2. Add the Raw Data:**
Ensure the 6 required Olist dataset files (orders, items, products, customers, sellers, geolocation) are placed inside the `data/` folder.

**3. Run the Feature Engineering Pipeline:**
Calculates Haversine distances, multi-modal carbon baselines, and K-Means hub clusters.

```
python src/data.py


```

**4. Run the ML Benchmarking Pipeline:**
Trains XGBoost & Neural Networks, computes cross-validation, and generates SHAP explainers.

```
python src/model.py


```

**5. Launch the Web Application:**
Starts the interactive Streamlit dashboard on your local server.

```
streamlit run app.py


```
